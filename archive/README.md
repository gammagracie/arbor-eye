# Archive

Pages set aside for now. They are not linked from the site's navigation, but they still work at these addresses:

| Page | Was | Address |
|---|---|---|
| `Gallery-horizontal.dc.html` | G4, horizontal-scroll gallery | `archive/Gallery-horizontal.dc.html` |
| `gallery-filmstrip.html` | G3, single-work filmstrip gallery | `archive/gallery-filmstrip.html` |
| `Gallery-boxed.dc.html` | grid gallery with grey boxes behind the works | `archive/Gallery-boxed.dc.html` |

Each page carries `<base href="../">` so its images, fonts and links resolve from the site root. To bring one back, move it to the root folder, delete that `<base>` line, and change any `archive/...` links in it back to the plain file name.

Not archived: `Gallery.dc.html` (the grid gallery) is out of the navigation but stays at the root, because it also hosts the detail page every gallery and the homepage open (`Gallery.dc.html#<file>`).
